- **A Jobs page lists every job across the fleet** (HMD-243). Jobs sits beside Services in the dashboard, under a Services | Jobs sub-tab, and under More on a phone; Home's Jobs card links to it. Failing jobs come first, then overdue ones, then the rest. Each job shows its schedule and scheduler, with its System's time zone when it differs from the viewer's, a strip of its last 14 runs (succeeded, failed, or a scheduled time no run followed before the next one or within the job's grace period), its latest run with when it started, how long it took, and its exit status, and when it is next due. The latest run and the job's state come from the same latest run and job Conditions as Home, and the strip adds that run when the run history does not hold it yet. A scheduled time older than the run history the Hub holds is never shown as missed. On a System whose Collector has sent no run history, a job shows its latest run and a strip marked as having no run history, not missed runs. A job that has never run shows an unknown level, not OK.
