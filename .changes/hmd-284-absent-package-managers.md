- **Maintenance no longer flags a package manager a System does not have** (HMD-284). An apt-only System lists APT alone and can read up to date, instead of saying its Homebrew check failed because the executable is missing. The Collector leaves out a default Homebrew prefix that has no Homebrew, and APT on a Linux that is not Debian-family; a prefix named in `homebrewPrefixes` is still expected, and a missing executable there still reads as a failed check. The Hub withdraws a package source a Collector stops reporting, with its pending packages and its Pending update note, so a removed Homebrew installation no longer keeps its System from reading up to date.
