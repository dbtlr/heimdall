- **Maintenance shows packages by the names people know, and one unreadable package check no longer breaks Home or Maintenance** (HMD-250). Homebrew packages drop the `formula:` prefix and casks are marked "cask"; APT packages drop the architecture when it is the System's own or `all`. A card lists packages by the name it shows, and hovering a package shows its full identity. When a stored package check cannot be read, that source has no current check and its Maintenance card says why, while every other source and System still shows. A stored pending package that cannot be read stays listed with its versions unknown. On Home, an unreadable package or reboot check makes that item's evidence old, and its note says the latest check could not be read rather than that none arrived.
