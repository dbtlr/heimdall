- **The Hub keeps each job's run history** (HMD-242). The Collector now sends every job run it keeps, not only each job's latest, and holds a run until the Hub takes it, so runs made between Reports or during a Hub outage still arrive. The Hub stores them in a new `job_runs` table and keeps 90 days of runs, and each job's latest 14 however old. Upgrade the Hub before its Collectors: a Hub that predates the history drops the runs, and `heimdall-collector pair` sends a Collector's kept runs to the Hub again.
