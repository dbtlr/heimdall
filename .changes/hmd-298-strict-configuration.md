- **A mistyped configuration key stops the binary** (HMD-298). A key that `hub.toml`, `collector.toml`, or `dashboard.toml` does not declare, or a value its schema or its option rejects, now stops the Hub, Collector, or dashboard with exit code 2 and a message that names the key, in every command, instead of running on the default. A Service whose file holds one does not start until the file is corrected. `-v` still names the file the run read.
