- **`-v` names a misspelled configuration key** (HMD-297). A key that `hub.toml`, `collector.toml`, or `dashboard.toml` does not declare used to be dropped silently. At `-v`, the start now writes `› Ignored <key> in <file>: Unknown key. Check its spelling, or remove it.` to the Service log, after a `› Read configuration from <file>.` line naming the file the binary read. The binary still starts without the key.
- **Heimdall runs on Loom 0.20** (HMD-297). The binaries read the same TOML and JSON files as before. `--config` naming a YAML file now fails with code 2. Words after a bare `--` now fill a command's arguments, so `heimdall-collector forget application -- demo` forgets `demo`; they used to be dropped, and a word with no argument left to fill now fails with code 2.
