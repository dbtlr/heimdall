### Added

- **Sessions in every worktree of a git repository share one project** (HMD-142). A Session that ran in a linked worktree, such as `.../worktrees/heimdall/fix-login`, is now filed under its repository, `heimdall`, instead of the worktree's folder name. The Collector reads which repository each Harness process's working directory belongs to, from git's pointer files only, and reports it; the Hub gives a Session the repository of the most recently started Harness process on its System seen in the same working directory, and `insight.sessions` gains a `repository` column. Upgrade the Hub first, then every Collector: a Hub older than this drops the `repository` a newer Collector sends, and a process that ends before the Hub is upgraded never gets it. Sessions with no matching Harness process, including all Sessions from before the upgrade, keep their folder-name project.
