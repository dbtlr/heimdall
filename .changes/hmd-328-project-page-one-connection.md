- **The project page reads in under a second on one connection** (HMD-328). The Hub now gives each Session one integer key, which every stored row of it carries and which a purge or a transcript delete that leaves the Session no generation removes, and stores with each Session's totals how many subagents have bursts of their own and the bounds of those bursts and of its tool calls. The page picks its Sessions and reads its history and branches in one statement, then matches the stored bursts and tool counts by that key. Its 30-day read for a project with 9,000 Sessions in the period (the heavy scenario) takes about 0.63 to 0.70 s p90 on one connection, against about 0.81 s p90 for the previous default read, which borrowed a second connection, and about 1.1 to 1.3 s on one connection. It no longer borrows a second connection. The upgrade takes about 11 seconds on 10,000 Sessions with 10 million requests.
