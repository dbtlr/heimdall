- **Session insight links each Session to the Session that launched it** (HMD-303). `insight.session_parents` resolves a Session's `launching_session_id` to the one held Session with that id, on any Harness, System, or source, or to the Session of a Codex subagent whose thread it names, and keeps the raw id with a `parent_state` when it cannot. The functions `insight.session_tree` and `insight.session_tree_total` read one Session's tree: the tree function lists every Session under it with each one's parent and depth, and the total function sums their stored totals, with no list-price cost while a member's totals are missing or a request is unpriced. A read is indexed lookups over the tree's members, their Codex subagents, and the Sessions that name them, never a scan of every Session held. A parent that arrives later resolves with no reparse. `docs/spec.md` documents the view and the functions under The insight views.
