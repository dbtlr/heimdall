### Added

- **The Hub derives Claude Code Session insight from the transcripts it holds** (HMD-65). `heimdall-hub serve` parses new transcript content every 15 seconds into each Session, subagent, request, and tool call, counting each response once however many lines or generations hold it. A parser version change rebuilds beside the old facts, which stay readable until the new version catches up, and a generation that cannot be parsed is recorded failed while the rest proceed. See [Session insight](docs/spec.md#session-insight).
- **The `insight` views** in the Hub's database read Session insight: Sessions, subagents, requests, tool calls, totals with and without subagents, and parse status. They carry facts and locators into the archive, never transcript content. See [The insight views](docs/spec.md#the-insight-views).
