### Added

- **The Hub derives Claude Code Session insight from the transcripts it holds** (HMD-65). `heimdall-hub serve` parses new transcript content every 15 seconds into each Session, subagent, request, and tool call, counting a response Claude Code wrote over several lines, or stored in two generations, once. A parser version change rebuilds the facts beside the old ones, which stay readable until the new version catches up. A generation that cannot be read or stored, or whose parse fails three runs in a row, is recorded failed and logged, and the rest proceed. Deleting transcripts deletes what was derived from them, and a touched Session reappears once it is derived again whole. See [Session insight](docs/spec.md#session-insight).
- **The `insight` views** in the Hub's database read Session insight: `insight.sessions`, `insight.subagents`, `insight.requests`, `insight.tool_calls`, totals with and without subagents in `insight.session_totals` and `insight.main_conversation_totals`, and the counts of failed generations and unreadable lines in `insight.parse_status`. They carry facts and locators into the archive, never transcript content, and a field that names or identifies something holds only a value shaped as one. See [The insight views](docs/spec.md#the-insight-views).
