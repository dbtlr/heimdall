- **Heimdall runs on Loom 0.18** (HMD-206). The Hub, Collector, and dashboard find their configuration file with Loom's lookup. It reads the first `.config/heimdall/<binary>.toml` or `.json` in the working directory and each directory above it below home (up to the filesystem root when the working directory is outside home), then the same file in home, then `config.toml` or `config.json` in `$XDG_CONFIG_HOME/heimdall-<binary>`, such as `~/.config/heimdall-hub` by default. Before, only the working directory and home were tried.
- **Help pages show each option's variable and configuration key** (HMD-206), as `env:` and `config:` lines.
- **`service install --port` refuses to create `hub.toml` or `dashboard.toml` when the binary's XDG configuration file exists** (HMD-206), as it already did beside a `.json` file of the same name, because the new file would hide it.
- **`--no-config`** (HMD-206). Every binary runs without reading a configuration file when given it, so a dotfile cannot change a run.
