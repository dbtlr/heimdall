- **A Maintenance page lists what can wait on each System** (HMD-244). The dashboard's Maintenance item and Home's Maintenance card open `/maintenance`: a sentence counting package updates, security updates, pending reboots, and Service updates, then a card per System, the ones with the most security updates first. Each card shows the System's package managers, a pending reboot and how long it has been required, its pending packages with security updates first, their installed and available versions, and how long each has been a security update, and the Services with an update, with when the update was found and from which upstream. A System with nothing pending shows when it was last checked.
