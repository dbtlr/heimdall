### Changed

- **Pending updates raise one Condition for each package source** (HMD-128). A System with several pending Homebrew or APT packages now shows one Pending update Condition per package source, at the worst level of its packages, instead of one per package. Its page lists the packages with their versions and security status, and says how to install them. On upgrade the Hub merges open per-package Conditions into one for each source, keeping the earliest raise time. Upgrade the Hub first.
