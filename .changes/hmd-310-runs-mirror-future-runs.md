- **The Hub no longer mirrors a run stamped past its clock** (HMD-310). A job whose latest run, or latest success, starts or finishes more than 5 minutes after the Hub's clock when the Report arrives now counts as unreadable, and the Hub keeps the latest runs it held for the job, so the dashboard shows its last readable run instead of a job that never ran. The same holds for every job a runs section counts unreadable. Its Conditions are not judged on that run and keep their state until a Report carries runs within the tolerance.
