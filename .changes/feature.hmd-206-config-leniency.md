- **A file that does not parse is skipped with a warning** (HMD-206). The binary then runs with no configuration file. A bad value inside a file still stops `serve` and `run` when it is in a section Heimdall checks itself: `[delivery]`, `[conditions]`, `[sessions]`, and `[updates]`. A top-level setting with the wrong type, such as a text `sleeps`, or one its option rejects, such as an `insight_reader` that is not a role name, is dropped, and the option falls back to its default.
- **A TOML date or time value inside a section Heimdall checks now reaches its checks as text** (HMD-206), so `topic = 2026-01-01` is accepted as the topic "2026-01-01". Loom reads dates that way.
