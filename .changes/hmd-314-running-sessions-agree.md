- **Agents and Home count a Session as running only when the sessions table marks it running** (HMD-314). Running, the sessions table, the totals, the cost chart, and Home's latest request all read requests up to 5 minutes past the dashboard's clock. A Collector whose clock runs far ahead no longer keeps a Session running, Running no longer counts a Session the table leaves unmarked, and the chart still sums to the total.
