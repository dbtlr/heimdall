- **A first start no longer rotates an empty log away** (HMD-207). A log's age now comes from its first timestamped line. Before, an untimestamped line written before the first rotation check, such as Loom's warning about a config file it cannot parse or an `Ignored` line at `-v`, made a fresh log look old, so it rotated at once and replaced the history in `<log>.1`. A log with no timestamped line is kept until it reaches 10 MB.
