- **A High memory Condition names the processes holding the most memory** (HMD-218). The Collector now reports the five processes with the most resident memory, by executable name and PID, on at most one sample a minute, and again on its first sample after a restart. The dashboard's sample inspector and the High memory Condition page list them with each one's resident memory. Resident memory counts shared pages in every process that maps them, so the rows overlap and are not summed. An older Collector never sends the list and an older Hub drops it, so either side can update first.
