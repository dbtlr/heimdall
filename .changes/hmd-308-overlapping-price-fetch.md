- **An overlapping price fetch no longer applies an older list over a newer one** (HMD-308). When a `serve` pass and `heimdall-hub prices update` overlapped, the fetch that started first could apply last and keep its older prices for up to a day. The Hub now numbers each fetch from a database sequence before it requests the list and skips a fetch that started before the last applied one, so a clock that steps cannot reorder them.
