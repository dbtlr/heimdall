- **The load chart shows the System's current core count** (HMD-236). Collectors report the operating system's logical CPU count, and the System overview's 1-minute load chart names the current count in its note and draws a labelled dashed line at it. The scale includes the line; Systems that have not reported a count keep their existing chart. Upgrade the Hub before the dashboard to apply migration 45: a dashboard upgraded first fails every System page because it selects the new column. Collectors may be upgraded in any order, since an older Hub ignores the field.
