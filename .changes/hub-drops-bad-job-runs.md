- **One bad job run no longer costs the whole Report** (HMD-257, HMD-256). The Hub drops a job run it cannot take, such as one with a broken field, a repeated start time, or a start time more than 5 minutes in the Hub's future, logs a warning, and stores the rest of the Report. Before, the Hub refused the whole Report, so that Report's records, latest runs, and checks were lost until the next hourly resend, and the same held job runs were refused again each hour.
