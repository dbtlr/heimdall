- **Activity opens on a shared time axis, and pins a moment that names the Sessions running and their cost** (HMD-246). Above the list, each System gets a lane on one axis over the range: its CPU busy with a dashed line at the limit the Hub stores, a bar for each stretch of an agent Session colored by Harness, and a mark for each change in the list. Drag across a lane, use the arrow keys on it, pick a mark, or pick the time of a line in the list to pin a moment. The pinned card shows the changes within 15 minutes on that System, the Sessions running then with each one's list-price cost and how long it has run, and that System's CPU, memory, and load, with a link to its page at that sample. The pin is in the URL, so the view can be linked. The axis draws about 144 CPU buckets a lane whatever the range, so the 30 day range reads no more than the 24 hour one. Activity replaces Compare: `/compare` redirects to `/activity`, and Home's link to it now opens Activity.
