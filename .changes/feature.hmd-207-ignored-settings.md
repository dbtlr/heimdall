- **`-v` names each config value a binary ignores** (HMD-207). A top-level setting with the wrong type, or one its option refuses, still falls back to the option's default, and `heimdall-hub`, `heimdall-dashboard`, and `heimdall-collector` now take `-v`, which writes one `Ignored …` line per dropped value to stderr. They also take `-q` to hide info and success messages.
- **The Services run with `-v`** (HMD-207), so each start writes every ignored config value to the Service log. Run `service install` again on each System to pick up the new arguments; until then the unit runs as before. See "A setting that has no effect" in `README.md`.
