- **A Service that refuses its config file stays stopped on Linux instead of restarting every 10 seconds** (HMD-312). The systemd unit no longer restarts the binary after exit code 2, Loom's refusal of the config file or invocation, so the refusal is logged once instead of growing the log past its rotation limit in about six days. Run `service install` once after updating to rewrite the unit, then `service restart` after fixing the file. Other failures still restart, and macOS's launchd agent still retries every exit.
