### Added

- **Collector reports which Harnesses are installed and their versions** (HMD-40). The Collector reads tool-manager install directories (mise, Claude Code's native installer, Homebrew) and global npm `package.json` files to find Claude Code and Codex, and never runs either. A Report's new `harnesses` section lists each install with its location kind and version, or `unknown` when the version cannot be read, and the Hub keeps the latest list per System and shows it in a Harnesses column on its page. Upgrade the Hub, which applies migration 13, before the Collectors. The spec documents where each version is read (`docs/spec.md`).
