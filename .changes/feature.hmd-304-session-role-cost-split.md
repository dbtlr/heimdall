- **Session insight splits list-price cost by role and review seat** (HMD-304). `insight.sessions` and `insight.subagents` gain `effective_role`, `effective_seat`, and `role_class`. A conversation's effective role is its own role, else the role of the nearest parent subagent that has one, else the role of the Session's main conversation. Only a review carries an effective seat. `role_class` is `review` for an effective role of `review`, `delegated` for any other role, and, when there is no effective role, `main` for a main conversation and `delegated` for a subagent. The new view `insight.session_role_totals` holds each Session's request counts and list-price cost per role class and review seat, with the priced subtotal and a count of unpriced requests when some have no price. The Hub stores the split and refreshes it with the Session's other stored totals, so it can lag a change by the same 15 seconds. `docs/spec.md` describes the rule under Cost by role and review seat.
