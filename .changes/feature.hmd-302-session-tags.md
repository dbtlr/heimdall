- **Session insight reads each conversation's session tag** (HMD-302). `insight.sessions` and `insight.subagents` gain `role`, `seat`, `launching_session_id`, and `role_source`. The parsers read them from the `session-tag:` line in a Session's or subagent's opening messages, or from T3 Code's sub-agent preamble when there is no tag. A Codex subagent has none of its own. Both parsers' versions move forward, so the Hub rebuilds Session insight once and fills these columns for every transcript it already holds. `docs/spec.md` describes the tag format under Session tags.
